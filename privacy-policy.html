Privacy Policy

Effective date: August 2026

Overview

vkt-note is a browser extension for Markdown note-taking with text selection support. All notes are stored locally in your browser using chrome.storage.local. No data is uploaded to any server.

Data Collection

vkt-note does NOT collect, transmit, or share any user data. Specifically:

  • ❌ No browsing history is collected
  • ❌ No analytics or telemetry
  • ❌ No cookies are read or written
  • ❌ No note content is sent to any server
  • ❌ No personal data is collected

Data Storage

Storage KeyContent
vkn_notesAll note data (title, Markdown content, timestamps, source URL)

Permissions

PermissionReason

contextMenusRight-click menu for creating notes from selected text or images
scriptingRequired for context menu interaction with page content

Important Notes

  • All notes are stored locally in your browser. They are not synced or backed up anywhere.
  • Switching browser profiles or uninstalling the extension will permanently delete all notes.
  • Exported JSON files are for manual backup only. The extension does not support importing notes.
  • Markdown images store remote URLs only. Images may not load if the source website is down or blocks hotlinking.

Third-Party Services

License key validation communicates with api.annmax1983.com. Only the license key, device hash, and plugin ID are sent. No notes or browsing data are transmitted.

Data Deletion

You can delete individual notes through the extension UI. Uninstalling the extension removes all stored data permanently.
