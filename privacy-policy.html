01Overview

vkt-note is a browser extension for Markdown note-taking with text selection support. All notes are stored locally in your browser using storage.local. Note content is never uploaded to any server.

The single outbound request the extension can make is the optional Premium license check described under Third-Party Services. It carries no note content, no page URLs, and no browsing history.

02Data Collection

vkt-note does NOT collect, sell, or share any user data. Specifically:

  • ❌ No browsing history is collected
  • ❌ No analytics or telemetry
  • ❌ No cookies are read or written
  • ❌ No note content is sent to any server
  • ❌ No personal data is collected

The one exception is the optional Premium license check. It is triggered only by activating a license key or by a periodic re-validation while a license is active, and it sends no note content. See Third-Party Services for the exact fields.

05Important Notes

  • All notes are stored locally in your browser. They are not synced or backed up automatically.
  • Optional passwords encrypt note content at rest with AES-256-GCM (PBKDF2-HMAC-SHA256, 600,000 iterations). Passwords and derived keys are never stored. Keys exist only in the side panel's memory and are dropped when it closes or you press Lock now.
  • Note titles, timestamps and word counts remain unencrypted so the note list can show them while content is locked.
  • There is no password recovery. A forgotten per-note password leaves permanent deletion as the only option; resetting a forgotten notebook password permanently deletes every note, Trash item and draft protected by it.
  • Switching browser profiles or uninstalling the extension will permanently delete all notes.
  • Exported JSON files are for manual backup only. Encrypted notes are exported as ciphertext, and the extension does not support importing notes, so those notes cannot be read or restored from the export. Keep a readable copy with Copy as Markdown or Download .md while the note is unlocked.
  • Markdown images store remote URLs only. Images may not load if the source website is down or blocks hotlinking.

06Third-Party Services

License key activation and periodic re-validation communicate with api.annmax1983.com. Each request contains the license key you entered, a randomly generated install identifier, the plugin ID, and basic technical metadata (browser name and major version, browser UI language, time zone, and user agent string). It never contains note content, exported notes, page URLs, or browsing history. Requests are made only when you activate or remove a license, or while a license is active and due for its periodic check. Our license server records the IP address of these requests solely for rate limiting and abuse prevention — never for profiling, advertising, or sharing with third parties.

07Data Retention & Deletion

You can delete individual notes through the extension UI. On Premium, deleted notes stay in Trash for 30 days and are then removed automatically; you can restore them or delete them permanently at any time before that. On the Free plan, deletion is permanent after the short undo window. A forgotten notebook password can only be reset by permanently deleting the items it protects. Uninstalling the extension removes all stored data permanently.
