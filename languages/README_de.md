| Funktion | Beschreibung |
|----------|-------------|
| 📝 **Speichern in vkt-note** | Rechtsklick auf Text oder Bild → erkennt Inhalt automatisch, wandelt HTML in Markdown um und speichert |

## Nutzung

### Notizen erstellen

1. **📝 vkt-note-Symbol** in der Symbolleiste klicken, um die Seitenleiste zu öffnen
2. **➕ Neue Notiz** klicken, um eine leere Notiz zu erstellen
3. Oder **Text auswählen** → Rechtsklick → **Speichern in vkt-note**
4. Oder **Rechtsklick auf Bild** → **Speichern in vkt-note**

### Webinhalte als Markdown kopieren

- **Rechtsklick auf Auswahl** → **Speichern in vkt-note**. Das HTML wird mit der Turndown-Bibliothek in Markdown umgewandelt.
- **Rechtsklick auf Bild** → **Speichern in vkt-note**. Der Bildlink wird als Markdown-Bild gespeichert.

### Bearbeitung

- Notizen werden **2 Sekunden** nach der Eingabe automatisch gespeichert
- **Speichern**-Button für sofortiges Speichern weiterhin verfügbar
- **👁 Vorschau** für Vollbild-Ansicht mit Zurück-Button
- **Quellseite-Link** wird in der Editor-Registerleiste angezeigt
