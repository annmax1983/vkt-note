# vkt-note

Markdown-Notiz-Tool mit Textauswahl für Chromium-Browser. Erstellen Sie Notizen von jeder Webseite per Rechtsklick.

> Chromium · Manifest V3 · SidePanel · Lokale Speicherung · 6 Sprachen

---

## Funktionen

| Funktion | Beschreibung |
|----------|-------------|
| 📝 **Textauswahl-Notizen** | Text auf jeder Webseite auswählen, Rechtsklick → Markdown-Notiz erstellen |
| 🖼 **Bild-Links** | Rechtsklick auf Bilder, um Bildlinks zur neuen Notiz hinzuzufügen |
| ✏️ **Markdown-Editor** | Quellbearbeitung + Live-Vorschau mit Tabellen, Bildern, Codeblöcken |
| 📎 **URL/Titel einfügen** | Ein-Klick-Einfügung der aktuellen Seiten-URL und des Titels |
| 🔒 **Lokale Speicherung** | Alle Notizen lokal im Browser, keine Cloud, kein Konto |
| 📋 **Tageskontingent** | Kostenlos 3 Notizen/Tag, Löschen gibt Kontingent frei |
| ⭐ **Premium** | Unbegrenzte Notizen und JSON-Export |
