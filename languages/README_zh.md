## 为什么选择 vkt-note？

大多数笔记插件需要注册账号、云端同步或付费订阅。vkt-note 不同：**笔记只存在你的浏览器里，不会上传。**

| 优势 | 说明 |
|------|------|
| 📝 **划词摘录** | 在任意网页选中文本，右键即可保存为Markdown笔记 |
| 🔒 **纯本地** | 所有笔记存储在 `storage.local` — 不上云、不注册、不追踪 |
| 🔐 **真正的加密** | 用密码保护单条笔记或整个笔记本 — 静态存储为 AES-256-GCM 密文，密钥从不保存 |
| ✏️ **Markdown编辑器** | 源码编辑 + 格式工具栏 + 自动保存 + Markdown 实时预览 |
| 🗑 **回收站** | 删除的笔记都可找回——免费版保留 7 天，高级版保留 30 天 |

## 使用说明

### 创建笔记

1. 点击浏览器工具栏中的 **📝 vkt-note 图标**，打开侧边栏
2. 点击 **➕ 新建笔记** 创建空白笔记
3. 或在网页上 **选中文本** → 右键 → **保存到 vkt-note**
4. 或 **右键图片** → **保存到 vkt-note**

### 复制网页内容为Markdown

- **右键选中内容** → **保存到 vkt-note**。选中内容的HTML通过 Turndown 库转换为Markdown。当选中内容在表格单元格内时，会自动扩展到完整的单元格、行或表格（最小完整单位）。
- **右键图片** → **保存到 vkt-note**。图片链接以Markdown图片格式保存到新笔记。
- **▦ 表格选择器**（工具栏）。列出当前页面所有表格；勾选一张或多张后点击**插入**，会转换为Markdown并按页面顺序追加（或在新建笔记中），页面同时回到所选表格并高亮。

### 格式工具栏

编辑器上方的工具栏提供快捷格式化：**加粗**、*斜体*、~~删除线~~、H1、H2、H3、链接、行内代码、代码块、无序列表、有序列表、引用、分割线。

### 编辑笔记

- 笔记在停止输入后 **2秒自动保存** — 无需手动点击保存
- **保存** 按钮仍可手动立即保存
- 点击 **👁 预览**，渲染后的 Markdown 会显示在编辑器的预览标签页中
- 预览说明：多层嵌套列表在预览中会平铺为单层（Markdown 源码本身始终完整保留）
- 右键保存的笔记自动用来源页面标题命名；新建空白笔记默认 `Note N` — 均可自由修改

### 整理笔记（高级版）

- **文件夹** — 在 **设置 → 管理文件夹** 中创建文件夹，然后在编辑器里归档单条笔记，或在批量模式下一次移动多条
- **标签** — 在编辑器里为每条笔记最多添加 12 个标签；点击筛选栏中的任意标签即可缩小列表
- **保存搜索** — 在筛选栏组合关键词、文件夹和标签，然后点击 **🔖 保存搜索**，最多可保留 30 组预设
- **批量模式** — 标题栏的 ☑ 按钮把列表切换为多选；一次完成移动、加标签或删除所选笔记
- **版本历史** — 打开笔记并点击 **🕘 历史**，浏览并恢复更早的快照；恢复操作本身也会被快照，可在历史列表里再次撤销

### 密码保护

加密是免费功能。密码从不保存，笔记在写入 `storage.local` 之前，已在本机使用 AES-256-GCM 加密。

- **笔记本密码** — 打开 **设置 → 笔记本密码** 进行设置。笔记列表（标题、日期和字数）保持可见；内容、摘要和基于内容的搜索匹配保持隐藏，直到解锁。每次打开面板只需输入一次。
- **单篇密码** — 打开笔记，点击编辑器标题栏中的 🔐/🔒 按钮，选择 **设置笔记密码**。该笔记随后使用自己的密码。单篇密码**优先于**笔记本密码，因此永远不会要求你同时输入两个。
- **立即锁定** — 点击面板标题栏中的 🔒 按钮，笔记本密钥和所有单篇密钥都会从内存中清除。关闭侧边栏效果相同。再次点击即可解锁。
- **移除密码** — 在笔记安全对话框中选择 **移除笔记密码**，或在设置中移除笔记本密码。移除笔记本密码会把受笔记本密码保护的笔记解密为本地明文；单篇密码会保留。
- **没有复杂度要求** — 任何非空密码都可以使用。
- **忘记密码** — 无法找回。删除笔记是绕过单篇密码的唯一方法。如果忘记了笔记本密码，**重置笔记本密码** 会永久删除受该密码保护的所有笔记和回收站项目，然后关闭笔记本密码；设置了单篇密码的笔记会保留。

加密笔记仍可按标题搜索，但锁定期间内容不会被索引，也不会显示在摘要中。JSON 导出从不解密：加密笔记以密文导出，导出对话框会先给出提示。由于插件不支持导入笔记，密文导出无法用于阅读这些笔记；如需可读副本，请先解锁笔记并使用 **复制为 Markdown** 或 **下载 .md**。启用笔记本密码期间，待处理的右键剪藏保存在 `storage.session` 中，因此其明文不会写入磁盘。

### 回收站

- 任意套餐下，删除笔记都会移入 **回收站**——不会有内容无声消失。
- 免费版回收站保留 **7 天**；高级版保留 **30 天**。超出时间窗口后项目自动删除。
- 在窗口内可以 **恢复** 或 **永久删除**；**清空回收站** 会立即清除全部内容，且无法撤销。
- 时间窗口跟随当前生效的套餐：如果高级版到期，超过 7 天的条目会在下一次每日清理时移除。
- 笔记列表里的 10 秒 **撤销** 是删除刚发生瞬间的快速通道；回收站是之后的保障。

### 免费版说明

- 新建笔记不设每日上限；免费版是一本完整的笔记本，不是试用版
- 编辑已有笔记始终不限量
- 整库 JSON 导出和 7 天回收站都包含在免费版中
- 笔记标题序号删除后不复用，允许跳号，属于正常设计

### 导出与下载

- **单条笔记 → .md 文件**：点击笔记卡片上的 ⬇ 图标，即可下载为Markdown文件（免费）
- **全部笔记 → JSON**（免费）：点击 **📥 导出** 下载整个笔记本为一个结构化 JSON 文件；设置了密码的笔记保持密文
- **增强导出**（高级版）：带图片打包的 Markdown ZIP、HTML 合集，或打印转 PDF，按文件夹布局
- 导出文件仅用于查阅备份，**插件不支持导入恢复笔记**，因此导出中的加密笔记无法从文件中读取或恢复

## 常见问题

1. **右键菜单不出现？**
   请确认已选中文本或右键点击了图片。菜单使用统一的「保存到 vkt-note」选项。

2. **重装后笔记丢失？**
   所有笔记存储在 `storage.local` 中。卸载扩展将永久删除所有数据。卸载前可先导出——整个笔记本可免费下载为一个 JSON 文件，设有密码的笔记以密文导出。

3. **笔记中的图片显示裂图？**
   Markdown图片仅存储远程URL。如果源站关闭、防盗链或图片被删除，图片将无法加载。

4. **可以导入导出的笔记吗？**
   不可以。JSON导出仅用于手动备份，插件不支持导入笔记。

5. **新建笔记有数量限制吗？**
   没有每日上限——想建多少建多少。高级版把回收站从 7 天延长到 30 天，并新增版本历史、文件夹与标签、保存搜索、批量操作和增强导出。

6. **忘记密码还能找回吗？**
   不能。密码从不保存，只保存一个无法据以还原加密的校验值。单篇密码只能通过删除该笔记绕过。忘记笔记本密码时，重置流程会永久删除受其保护的所有笔记和回收站项目；设置了单篇密码的笔记会保留。

7. **笔记本锁定时还能看到笔记标题吗？**
   可以。标题、时间和字数按设计保持可见，方便你找到需要的笔记；内容、摘要和基于内容的搜索匹配在解锁前保持隐藏，标题搜索仍可使用。

8. **加密笔记在导出中是什么样子？**
   它们以密文导出，而不是明文。包含加密笔记时，导出对话框会给出提示。由于插件不支持导入笔记，JSON 文件无法用于读取或重新导入这些笔记。如需可读副本，请先解锁笔记并使用 **复制为 Markdown** 或 **下载 .md**。

9. **删除的笔记去了哪里？**
   所有删除都会进入回收站——免费版 7 天内可恢复，高级版 30 天。10 秒撤销覆盖删除的瞬间。

## 隐私说明

vkt-note 遵循隐私优先原则：

- ✅ 所有笔记存储在 `storage.local` — **笔记内容不会上传到任何服务器**
- ✅ 可选的密码保护使用 AES-256-GCM 加密静态存储的笔记内容（PBKDF2-HMAC-SHA256，600,000 次迭代）；密码与派生密钥从不保存，也不传输
- ✅ 我们服务器收到的唯一请求，是可选的 Premium 许可证校验（许可证密钥、随机安装标识、基础浏览器信息）— 不含笔记与页面 URL。扩展还可能加载您的笔记中已存在的图片外链（Markdown 预览、高级版带图片导出）— 这类请求只发往图片所在站点，不会发给我们
- ✅ 无分析、无追踪、无Cookie
- ✅ 仅在你主动操作时访问页面内容（右键保存、插入按钮、表格选择）— 后台绝不读取任何页面
- ✅ 导出的JSON文件在本地生成，不外传；加密笔记在导出中保持密文

### 权限说明

| 权限 | 用途 |
|------|------|
| `storage` | 本地保存笔记和设置 |
| `unlimitedStorage` | 提升默认本地存储上限，避免长笔记历史触发写入失败 |
| `sidePanel` | 显示扩展侧边栏界面 （仅 Chrome / Edge） |
| `contextMenus` | 右键菜单创建笔记 |
| `scripting` | 仅在你触发保存 / 插入 / 表格操作时注入转换器 |
| `alarms` | 运行每日清理任务——按当前套餐移除超期的回收站条目（免费 7 天 / 高级版 30 天），并清理过期的版本历史 |
| 主机权限 `<all_urls>` | 使上述主动操作能读取当前页面的选中内容、表格、URL 和标题 — 不做后台访问，不收集浏览记录 |
