## 为什么选择 vkt-note？

大多数笔记插件需要注册账号、云端同步或付费订阅。vkt-note 不同：**所有数据留在你的浏览器里，零数据外传。**

| 优势 | 说明 |
|------|------|
| 📝 **划词摘录** | 在任意网页选中文本，右键即可创建Markdown笔记 |
| 🔒 **纯本地** | 所有笔记存储在 `chrome.storage.local` — 不上云、不注册、不追踪 |
| ✏️ **Markdown编辑器** | 源码编辑 + 实时预览，支持表格、图片、代码块、链接等完整语法 |
| 📎 **来源追踪** | 一键插入当前网页URL和标题，笔记来源一目了然 |
| 📋 **智能额度** | 免费每日3条；删除当日笔记归还额度 — 永远不会被锁死 |
| 🌍 **6种语言** | English、中文、日本語、Deutsch、Español、Français |

## 安装方式

为安全起见，请仅通过官方浏览器扩展商店安装：

1. 打开 **Chrome Web Store** 或 **Microsoft Edge Add-ons**
2. 搜索：`vkt-note`

## 使用说明

### 创建笔记

1. 点击浏览器工具栏中的 **📝 vkt-note 图标**，打开侧边栏
2. 点击 **➕ 新建笔记** 创建空白笔记
3. 或在网页上 **选中文本** → 右键 → **选中内容新建Markdown笔记**
4. 或 **右键图片** → **将图片链接添加到新笔记**

### 编辑笔记

- 通过 **编辑**（源码）和 **预览**（渲染）标签页切换模式
- 点击 **📎 插入URL** 按钮插入当前页面的Markdown链接
- 点击 **📑 插入标题** 按钮插入当前页面标题
- 标题自动生成为 `笔记YYYYMMDD_N` — 可自由修改

### 免费版规则

- 免费版每日最多新建 **3条笔记**
- 仅点击 **保存** 新建 **新笔记** 才消耗额度
- 编辑已有笔记 **不消耗** 额度
- 删除 **当日创建** 的笔记，归还一个额度
- 删除 **历史日期** 的笔记，不影响今日额度
- 笔记标题序号删除后不复用，允许跳号，属于正常设计

### 导出功能（仅高级版）

- 高级版用户可点击 **📥 导出** 下载全部笔记为JSON文件
- 导出文件仅用于查阅备份，**插件不支持导入恢复笔记**

## 常见问题

1. **右键菜单不出现？**
   请确认已选中文本。菜单仅在选中文本或右键图片时出现。

2. **重装后笔记丢失？**
   所有笔记存储在 `chrome.storage.local` 中。卸载扩展将永久删除所有数据。卸载前请先导出笔记（高级版功能）。

3. **笔记中的图片显示裂图？**
   Markdown图片仅存储远程URL。如果源站关闭、防盗链或图片被删除，图片将无法加载。

4. **可以导入导出的笔记吗？**
   不可以。JSON导出仅用于手动备份，插件不支持导入笔记。

5. **如何获得更多额度？**
   删除今日创建的笔记释放额度，或升级高级版获得无限笔记。

## 隐私说明

vkt-note 遵循隐私优先原则：

- ✅ 所有笔记存储在 `chrome.storage.local` — **不上传任何服务器**
- ✅ 无分析、无追踪、无Cookie
- ✅ 不申请 `<all_urls>` 权限 — 仅在用户主动触发插入或右键菜单时访问页面内容
- ✅ 导出的JSON文件在本地生成，不外传

### 权限说明

| 权限 | 用途 |
|------|------|
| `storage` | 本地保存笔记、草稿和设置 |
| `activeTab` | 点击插入按钮时获取当前页面URL/标题 |
| `sidePanel` | 显示扩展侧边栏界面 |
| `contextMenus` | 右键菜单创建笔记 |
| `scripting` | 右键菜单与页面内容交互所需 |

- [完整隐私条款](https://annmax1983.github.io/vkt-note/privacy-policy.html)
