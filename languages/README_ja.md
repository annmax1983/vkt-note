公式ユーザーマニュアル · Chromiumブラウザ向けの軽量Markdownノート拡張機能（テキスト選択対応）。

> Chrome / Edge / Firefox · Manifest V3 · サイドパネル / サイドバー · ローカル保存

---

## vkt-noteを選ぶ理由

ほとんどのノート拡張機能はアカウント登録やクラウド同期、サブスクリプションが必要です。vkt-noteは違います。**ノートはブラウザ内に保存され、外部に送信されることはありません。**

| メリット | 詳細 |
|----------|------|
| 📝 **テキスト選択** | 任意のウェブページでテキストを選択し、右クリックですぐにMarkdownノートとして保存 |
| 🔒 **ローカルのみ** | すべてのノートは`storage.local`に保存 — クラウド不要、アカウント不要、トラッキングなし |
| 🔐 **本物の暗号化** | 1件のノートまたはノートブック全体をパスワードで保護 — 保存時はAES-256-GCMの暗号文、鍵は保存されません |
| ✏️ **Markdownエディタ** | ソース編集＋フォーマットツールバー＋自動保存＋Markdownライブプレビュー |
| 🗑 **ゴミ箱（Premium）** | Premiumでの削除は30日間復元可能で、その後は自動的に削除されます |

## 使い方

### ノートの作成

1. ツールバーの**📝 vkt-noteアイコン**をクリックしてサイドバーを開く
2. **➕ 新規ノート**をクリックして空白ノートを作成
3. またはページ上で**テキストを選択** → 右クリック → **vkt-noteに保存**
4. または**画像を右クリック** → **vkt-noteに保存**

### ウェブコンテンツをMarkdownとしてコピー

- **選択テキストを右クリック** → **vkt-noteに保存**。選択範囲のHTMLがTurndownライブラリでMarkdownに変換されます。選択範囲がテーブルセル内にある場合、完全なセル・行・テーブル（最小の完全単位）に拡張されます。
- **画像を右クリック** → **vkt-noteに保存**。画像リンクが新しいノートにMarkdown画像として保存されます。
- **▦ テーブル選択**（ツールバー）。現在のページの全テーブルを一覧表示。1件または複数を選んで**挿入**をクリックすると、ページ順にMarkdownとして追記され（または新規ノートに挿入され）、選択したテーブルへページがスクロールしてハイライトされます。

### フォーマットツールバー

エディタ上のツールバーで素早くフォーマット可能：**太字**、*斜体*、~~取り消し線~~、H1、H2、H3、リンク、インラインコード、コードブロック、箇条書き、番号付きリスト、引用、区切り線。

### ノートの編集

- 入力停止から**2秒後**に自動保存 — 手動で保存ボタンを押す必要なし
- **保存**ボタンで即時保存も可能
- **👁 プレビュー**をクリックすると、レンダリングされたMarkdownがエディタのプレビュータブに表示されます
- 右クリックで保存したノートはソースページのタイトルを引き継ぎ、新規の空白ノートは`Note N`から始まります — どちらも自由に編集可能

### パスワード保護

暗号化は無料機能です。パスワードは保存されず、ノートは`storage.local`に書き込まれる前に、この端末上でAES-256-GCMにより暗号化されます。

- **ノートブックのパスワード** — **設定 → ノートブックのパスワード**を開いて設定します。ノート一覧（タイトル、日付、文字数）は表示されたままですが、内容、スニペット、内容に基づく検索一致は解除するまで非表示です。パスワードの入力はパネルセッションごとに1回です。
- **ノートごとのパスワード** — ノートを開き、エディタヘッダーの🔐/🔒ボタンをクリックして**ノートのパスワードを設定**を選びます。そのノートは専用のパスワードを使うようになります。ノートごとのパスワードはノートブックのパスワードより**優先**されるため、両方を聞かれることはありません。
- **今すぐロック** — パネルヘッダーの🔒ボタンで、ノートブックの鍵とすべてのノートの鍵をメモリから破棄します。サイドバーを閉じても同じ効果があります。もう一度クリックすると解除できます。
- **パスワードの削除** — ノートのセキュリティダイアログを開いて**ノートのパスワードを削除**を選ぶか、設定でノートブックのパスワードを削除します。ノートブックのパスワードを削除すると、保護されていたノートはローカルの平文に復号されます。ノートごとのパスワードは保持されます。
- **複雑さの要件なし** — 空でないパスワードなら何でも受け付けます。
- **パスワードを忘れた場合** — 復元はできません。ノートごとのパスワードを回避する唯一の方法は、そのノートを削除することです。ノートブックのパスワードを忘れた場合は、**ノートブックのパスワードをリセット**すると、そのパスワードで保護されたすべてのノート、ゴミ箱の項目、ドラフトが完全に削除され、ノートブックのパスワードがオフになります。独自のパスワードを持つノートは残ります。

暗号化されたノートはタイトルでは検索できますが、ロック中は内容がインデックスされず、スニペットにも表示されません。JSONエクスポートは決して復号しません。暗号化されたノートは暗号文のまま書き出され、エクスポートダイアログが事前に警告します。この拡張機能はインポートに対応していないため、暗号文のエクスポートからこれらのノートを読むことはできません。読めるコピーを残すには、ノートを解除して**Markdownとしてコピー**または**.mdをダウンロード**を使用してください。ノートブックのパスワードが有効な間、保留中の右クリッククリップは`storage.session`に保持されるため、その平文がディスクに書き込まれることはありません。

### ゴミ箱（Premium）

- Premiumが有効な場合、ノートを削除すると消去されるのではなく**ゴミ箱**に移動します。
- ゴミ箱の項目は**30日以内**ならいつでも復元でき、それ以降は自動的に削除されます。
- **ゴミ箱を空にする**と**完全に削除**は即座に項目を削除し、元に戻すことはできません。
- 無料プランでの削除は完全削除です。復元できるのは7秒間の元に戻す操作だけです。
- Premiumが期限切れになっても、既存のゴミ箱の項目は復元または削除できます。無料プランのルールに従うのは新たな削除だけです。

### 無料版の説明

- 新規ノートの1日あたりの上限はありません。無料版は試用版ではなく、完全なノートブックです
- 既存ノートの編集は常に無制限
- 削除後、ノートタイトルの連番にスキップが生じることがあります — 仕様です

### エクスポートとダウンロード

- **単一ノート → .mdファイル**：ノートカードの ⬇ アイコンをクリックするとMarkdownファイルとしてダウンロードできます（無料）
- **全ノート → JSON**（Premium）：**📥 エクスポート**をクリックして全ノートを構造化JSONファイルとしてダウンロード。パスワード付きノートは暗号文のままです
- エクスポートファイルはバックアップ/参照用です — **ノートのインポートには対応していない**ため、暗号化されたノートはファイルから読むことも復元することもできません

## よくある質問

1. **右クリックメニューが表示されない？**
   テキスト選択時または画像の右クリック時にメニューが表示されます。統合された「vkt-noteに保存」オプションを使用します。

2. **再インストール後にノートが消えた？**
   すべてのノートは`storage.local`に保存されています。拡張機能をアンインストールすると全データが完全に削除されます。アンインストール前にノートをエクスポートしてください（Premiumは全ノートを1つのJSONファイルにまとめて書き出し、パスワード付きノートは暗号文のままです。無料版でもノートを1件ずつコピーまたはダウンロードできます）。

3. **ノート内の画像が表示されない？**
   Markdown画像はリモートURLのみを保存します。ソースサイトがダウンしている場合、ホットリンクをブロックしている場合、または画像が削除されている場合、画像は表示されません。

4. **エクスポートしたノートをインポートできる？**
   いいえ。JSONエクスポートは手動バックアップ用です。拡張機能はノートのインポートに対応していません。

5. **作成できるノート数に上限はありますか？**
   いいえ。無料版・Premium とも新規作成数に制限はありません。Premium では一括 JSON エクスポートと 30 日間のゴミ箱が追加されます。

6. **パスワードを忘れました。復元できますか？**
   いいえ。パスワードは保存されず、暗号化を逆算できない検証子だけが保存されます。ノートごとのパスワードを回避するには、そのノートを削除するしかありません。ノートブックのパスワードを忘れた場合、リセット操作により、それで保護されたすべてのノート、ゴミ箱の項目、ドラフトが完全に削除されます。ノートごとのパスワードで保護されたノートは残ります。

7. **ノートブックがロックされていてもタイトルは見えますか？**
   はい。タイトル、タイムスタンプ、文字数は目的のノートを見つけられるよう仕様として表示されたままです。内容、スニペット、内容に基づく検索一致は解除するまで非表示です。タイトル検索は引き続き利用できます。

8. **暗号化されたノートはエクスポートでどう見えますか？**
   平文ではなく暗号文として書き出されます。エクスポートダイアログは、暗号化されたノートが含まれる場合に警告します。この拡張機能はインポートに対応していないため、JSONファイルからこれらのノートを読んだり再インポートしたりすることはできません。読めるコピーを残すには、ノートを解除して**Markdownとしてコピー**または**.mdをダウンロード**を使用してください。

9. **削除したノートはどこへ行きますか？**
   Premiumではゴミ箱に入り、30日間復元できます。無料プランでは、7秒間の元に戻す操作を過ぎると完全に削除されます。

## プライバシー

vkt-noteはプライバシーバイデザインの原則に従っています：

- ✅ 全ノートを`storage.local`に保存 — **ノートの内容がサーバーに送信されることはありません**
- ✅ 任意のパスワード保護により、ノートの内容は保存時にAES-256-GCM（PBKDF2-HMAC-SHA256、600,000回）で暗号化されます。パスワードと派生鍵が保存・送信されることはありません
- ✅ 外部通信は任意のPremiumライセンス確認のみ（ライセンスキー、ランダムなインストール識別子、基本的なブラウザ情報） — ノートやページURLは送信しません
- ✅ 分析・トラッキング・Cookieなし
- ✅ ページコンテンツは明示的な保存/挿入/テーブル選択のトリガー時のみアクセス（コンテキストメニュー、挿入ボタン、テーブル選択） — バックグラウンドでのアクセスなし
- ✅ エクスポートされたJSONファイルはローカルで作成され、送信されることはありません。暗号化されたノートはエクスポートでも暗号文のままです

### 権限

| 権限 | 理由 |
|------|------|
| `storage` | ノートと設定をローカルに保存 |
| `unlimitedStorage` | 既定のローカルストレージ上限を引き上げ、長いノート履歴でも書き込みエラーが発生しないようにする |
| `sidePanel` | サイドバーに拡張機能UIを表示 （Chrome / Edge のみ） |
| `contextMenus` | テキスト選択または画像からノートを作成するための右クリックメニュー |
| `scripting` | 保存/挿入/テーブル操作トリガー時にのみHTML→Markdownコンバーターを注入 |
| `alarms` | 30日を超えたゴミ箱の項目を削除する日次ジョブを実行 |
| Host `<all_urls>` | 上記アクションで現在のページの選択範囲・テーブル・URL・タイトルを読み取り — バックグラウンドや閲覧履歴へのアクセスなし |
