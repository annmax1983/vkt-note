# vkt-note

[English](../README.md) | [中文](README_zh.md) | [Deutsch](README_de.md) | [Español](README_es.md) | 日本語 | [Français](README_fr.md)

テキスト選択対応Markdownノートツール（Chromiumブラウザ向け）。任意のウェブページで右クリックからノートを作成。

> Chromium · Manifest V3 · SidePanel · ローカル保存

---

## 機能

| 機能 | 説明 |
|------|------|
| 📝 **vkt-noteに保存** | テキストまたは画像を右クリック→コンテンツを自動検出し、HTMLをMarkdownに変換して保存 |
| ✏️ **Markdownエディタ** | ソース編集＋フォーマットツールバー＋自動保存＋フルスクリーンプレビュー |
| 🧩 **HTML→Markdown** | Turndownライブラリ（業界標準）を使用し、テーブル・見出し・リスト・リンク・コードブロック・画像などを高精度に変換 |
| ▦ **テーブル選択** | 現在のページの全テーブルを一覧表示→クリックでMarkdownテーブルとして挿入 |
| 📎 **URL挿入** | ワンクリックで現在のページURLをMarkdownリンクとして挿入 |
| 📑 **タイトル挿入** | ワンクリックで現在のページタイトルを挿入 |
| 🔗 **ソースページリンク** | エディタのタブバーにクリック可能なソースリンクを表示 |
| 🛠️ **フォーマットツールバー** | 太字・斜体・取り消し線・H1〜H3・リンク・インラインコード・コードブロック・箇条書き・番号付きリスト・引用・区切り線 |
| 💾 **自動保存** | 編集から2秒後に自動保存。手動で保存ボタンを押す必要なし |
| 🔒 **ローカル保存** | 全ノートをブラウザに保存、クラウド不要、アカウント不要 |
| 📋 **日次制限** | 無料版1日3件、当日ノート削除で枠回復 |
| ⭐ **Premium** | 無制限ノート＋JSONエクスポート |

## 使い方

### ノートの作成

1. ツールバーの **📝 vkt-noteアイコン** をクリックしてサイドバーを開く
2. **➕ 新規ノート** をクリックして空白ノートを作成
3. またはページ上で **テキストを選択** → 右クリック → **vkt-noteに保存**
4. または **画像を右クリック** → **vkt-noteに保存**

### ウェブコンテンツをMarkdownとしてコピー

- **選択テキストを右クリック** → **vkt-noteに保存**。HTMLがTurndownライブラリでMarkdownに変換されます。
- **画像を右クリック** → **vkt-noteに保存**。画像リンクがMarkdown画像として保存されます。


### 編集

- 入力停止から **2秒後** に自動保存されます
- **保存** ボタンで即時保存も可能
- **👁 プレビュー** でフルスクリーン表示（戻るボタン付き）
- **ソースページリンク** がエディタのタブバーに表示されます
