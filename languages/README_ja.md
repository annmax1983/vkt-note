## vkt-noteを選ぶ理由

ほとんどのノート拡張機能はアカウント登録やクラウド同期、サブスクリプションが必要です。vkt-noteは違います。**すべてブラウザ内に保存され、データがデバイスの外に出ることはありません。**

| メリット | 詳細 |
|----------|------|
| 📝 **テキスト選択** | 任意のウェブページでテキストを選択し、右クリックですぐにMarkdownノートとして保存 |
| 🔒 **ローカルのみ** | すべてのノートは`chrome.storage.local`に保存 — クラウド不要、アカウント不要、トラッキングなし |
| ✏️ **Markdownエディタ** | ソース編集＋フォーマットツールバー＋自動保存＋フルスクリーンプレビュー |
| 🛡 **ドラフト保護** | 上限で保存できなかった新規ノートはローカルドラフトとして保持 — 入力内容が黙って失われることはありません |
| 📋 **スマートクォータ** | 無料版1日3件。当日のノート削除で枠を回復 — ロックアウトなし |

## インストール

セキュリティのため、公式ブラウザ拡張ストアからのみvkt-noteをインストールしてください：

1. **Chrome Web Store**または**Microsoft Edgeアドオン**を開く
2. 検索：`vkt-note`
3. **「Chromeに追加」**/**「Edgeに追加」**をクリック
4. ツールバーの📝 vkt-noteアイコンをクリックしてサイドバーを開く

> ⚠️ サードパーティのウェブサイトからのインストールはおやめください。未承認のバージョンはデータセキュリティを脅かす可能性があります。

## 使い方

### ノートの作成

1. ツールバーの**📝 vkt-noteアイコン**をクリックしてサイドバーを開く
2. **➕ 新規ノート**をクリックして空白ノートを作成
3. またはページ上で**テキストを選択** → 右クリック → **vkt-noteに保存**
4. または**画像を右クリック** → **vkt-noteに保存**

### ウェブコンテンツをMarkdownとしてコピー

- **選択テキストを右クリック** → **vkt-noteに保存**。選択範囲のHTMLがTurndownライブラリでMarkdownに変換されます。選択範囲がテーブルセル内にある場合、完全なセル・行・テーブル（最小の完全単位）に拡張されます。
- **画像を右クリック** → **vkt-noteに保存**。画像リンクが新しいノートにMarkdown画像として保存されます。
- **▦ テーブル選択**（ツールバー）。現在のページの全テーブルを一覧表示。クリックで開いているノートにMarkdownテーブルとして挿入（または新規ノートに挿入）。

### フォーマットツールバー

エディタ上のツールバーで素早くフォーマット可能：**太字**、*斜体*、~~取り消し線~~、H1、H2、H3、リンク、インラインコード、コードブロック、箇条書き、番号付きリスト、引用、区切り線。

### ノートの編集

- 入力停止から**2秒後**に自動保存 — 手動で保存ボタンを押す必要なし
- **保存**ボタンで即時保存も可能
- **👁 プレビュー**でフォーマット済みコンテンツを**フルスクリーン表示**（戻るボタン付き） — エディタのUI非表示
- **上限ドラフト**：1日上限に達して新規ノートが保存できない場合、内容はローカルに保持され、次回パネルを開いたときに復元を確認します
- タイトルは自動的に`Note N`として生成 — 自由に編集可能

### 無料版のルール

- 無料版：1日最大**3件の新規ノート**
- **新規**ノートの作成のみ日次カウントに加算（手動保存・2秒自動保存の両方を含む）
- 既存ノートの編集はクォータを**消費しない**
- **当日**作成されたノートを削除すると1枠回復
- 前日以前のノートを削除しても当日のクォータに**影響なし**
- 上限で新規ノートの保存がブロックされた場合、内容はローカルドラフトとして保存されます — 24時間以内にパネルを開き直せば復元できます
- 削除後、ノートタイトルの連番にスキップが生じることがあります — 仕様です

### エクスポート（Premium限定）

- Premiumユーザーは**📥 エクスポート**をクリックして全ノートをJSONファイルとしてダウンロード可能
- エクスポートファイルはバックアップ/参照用です — **ノートのインポートには対応していません**

## よくある質問

1. **右クリックメニューが表示されない？**
   テキスト選択時または画像の右クリック時にメニューが表示されます。統合された「vkt-noteに保存」オプションを使用します。

2. **再インストール後にノートが消えた？**
   すべてのノートは`chrome.storage.local`に保存されています。拡張機能をアンインストールすると全データが完全に削除されます。アンインストール前にノートをエクスポートしてください（Premium機能）。

3. **ノート内の画像が表示されない？**
   Markdown画像はリモートURLのみを保存します。ソースサイトがダウンしている場合、ホットリンクをブロックしている場合、または画像が削除されている場合、画像は表示されません。

4. **エクスポートしたノートをインポートできる？**
   いいえ。JSONエクスポートは手動バックアップ用です。拡張機能はノートのインポートに対応していません。

5. **1日3件以上のノートを作成するには？**
   当日作成したノートを削除して枠を解放するか、Premiumにアップグレードして無制限ノートを利用してください。

## プライバシー

vkt-noteはプライバシーバイデザインの原則に従っています：

- ✅ 全ノートを`chrome.storage.local`に保存 — **データは一切サーバーに送信されません**
- ✅ 分析・トラッキング・Cookieなし
- ✅ ページコンテンツは明示的な保存/挿入/テーブル選択のトリガー時のみアクセス（コンテキストメニュー、挿入ボタン、テーブル選択） — バックグラウンドでのアクセスなし
- ✅ エクスポートされたJSONファイルはローカルで作成され、送信されることはありません

### 権限

| 権限 | 理由 |
|------|------|
| `storage` | ノートと設定をローカルに保存 |
| `sidePanel` | サイドバーに拡張機能UIを表示 |
| `contextMenus` | テキスト選択または画像からノートを作成するための右クリックメニュー |
| `scripting` | 保存/挿入/テーブル操作トリガー時にのみHTML→Markdownコンバーターを注入 |
| Host `<all_urls>` | 上記アクションで現在のページの選択範囲・テーブル・URL・タイトルを読み取り — バックグラウンドや閲覧履歴へのアクセスなし |
