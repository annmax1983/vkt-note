# vkt-note

[English](../README.md) | [中文](README_zh.md) | [Deutsch](README_de.md) | [Español](README_es.md) | 日本語 | [Français](README_fr.md)

テキスト選択対応Markdownノートツール（Chromiumブラウザ向け）。任意のウェブページで右クリックからノートを作成。

> Chromium · Manifest V3 · SidePanel · ローカル保存 · 6言語対応

---

## 機能

| 機能 | 説明 |
|------|------|
| 📝 **テキスト選択ノート** | 任意のページでテキスト選択→右クリック→Markdownノート作成 |
| 🖼 **画像リンク** | 画像を右クリックしてリンクを新規ノートに追加 |
| ✏️ **Markdownエディタ** | ソース編集＋ライブプレビュー、テーブル・画像・コードブロック対応 |
| 📎 **URL/タイトル挿入** | ワンクリックで現在のページURLとタイトルを挿入 |
| 🔒 **ローカル保存** | 全ノートをブラウザに保存、クラウド不要、アカウント不要 |
| 📋 **日次制限** | 無料版1日3件、当日ノート削除で枠回復 |
| ⭐ **Premium** | 無制限ノート＋JSONエクスポート |
