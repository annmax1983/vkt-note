Markdown Note-Taking

VKT Note is a Markdown note-taking extension for Chrome and Edge that keeps a notebook in the browser side panel. Select text on any page, right-click, and it arrives as a clean Markdown note titled after the source; images come in as Markdown links and tables as real tables. Write and edit in the same panel while the page stays visible, preview the formatting, and keep every note on your own device. No account, no ads, no tracking.

01

Everything it does

The core features at a glance.

01

Save any selection with a right-click; the note is titled after the page.

02

Right-click an image to save it as a Markdown image link.

03

Table picker lists every table on the page, inserts your picks in page order and highlights them on the page.

04

A formatting toolbar for bold, italic, strikethrough, headings, links, inline code, code blocks, lists, quotes and horizontal rules.

05

Live preview renders headings, lists, tables, task lists and code.

06

Notes save themselves two seconds after you stop typing.

Also included

  • Undo a deletion within seven seconds and the quota slot returns with it.
  • Pin important notes to the top and search the rest by title and content.
  • Copy any note as Markdown or download it as a .md file.
  • A status bar counts notes and words, treating Chinese, Japanese and Korean characters as words rather than bytes.

02

Free vs Premium

The free tier is a complete tool, not a trial. Premium is optional.

Free

three new notes per day, unlimited editing of notes you already have, selection, image and table clipping, the table picker, editor and preview, auto-save, pin, search, copy as Markdown, single-note .md download, seven-second undo and the draft queue.

Premium

unlimited new notes and a full export of every note as one JSON file. One licence key activates on two browsers, and removing the licence from one browser frees that slot again.

Deleting a note you created today returns its slot immediately, and editing an existing note never uses one. The free plan is a working notebook, not a countdown.

Private by design

Your data stays on your device. No account, no analytics, no tracking. Read exactly what is stored and when the extension uses the network.
